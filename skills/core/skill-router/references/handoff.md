# Minimal handoff

Use a short conversation note for small work. For larger work, store it with
the target project's existing spec/plan, never in the reusable skill library.
Do not duplicate facts already available in an authoritative document.

```text
Target project and ref:
Task / current mode:
Current stage:
Confirmed requirements + sources:
Proposed defaults (not confirmed requirements):
Blocking decisions:
Spec / plan revision:
Implementation authorization + scope + source:
Completed changes and evidence:
Not verified / limitations:
Next skill or available host capability:
Next action:
```

On resume, re-read relevant project rules, current files and this note. Check
whether changes invalidate prior decisions or approval. Reopen only affected
questions; do not repeat the whole interview. Never mark an agent-authored
"approved" field as user approval without a real conversation or review source.
