# Core

[skill-router](skill-router/SKILL.md) selects the next useful capability and
preserves task context. It does not implement application features, grant tool
permissions, or require a multi-agent runtime.

[interactive-learning](interactive-learning/SKILL.md) preserves a stable learning
roadmap while allowing deep follow-up questions. It manages current position,
question branches, return points, parking-lot topics, checkpoints, and active
recall without replacing domain-specific evidence or implementation skills.

The repository catalog lives in [INDEX.md](../INDEX.md). Use the host's registry
when the router is installed without the rest of this repository.
