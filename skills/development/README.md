# Development

This domain contains engineering-process skills. Use the
[canonical index](../INDEX.md) to find their entries.

`development-discovery` guides new-project and new-feature decisions before
coding. It inspects the target project, offers options and a recommendation,
and produces an appropriately sized spec, implementation plan and readiness
record. Critical unknowns block the affected implementation, not read-only
research or clearly separated, already authorized work.

`learn-codebase` serves an explicit learning goal. Routine repository inspection
inside a development task should not trigger its teaching dialogue.

UI requirements are delegated only after the relevant product/system decisions
are stable. The library currently has no dedicated backend implementation skill;
an approved backend plan can use the host's normal coding capability.
