# Writing Skills

Writing skills turn existing evidence, analysis, and engineering work into reusable written artifacts.

## Skills

| Skill | Use it to | Primary output |
| --- | --- | --- |
| [write-evidence-driven-blog](write-evidence-driven-blog/SKILL.md) | Turn technical investigation, architecture decisions, debugging, or project work into an evidence-driven Chinese technical article | Publishable draft |

Writing skills should not invent missing technical evidence. When understanding of a repository or implementation is insufficient, gather evidence first (for example with `development/learn-codebase`) and then return to the writing task.
